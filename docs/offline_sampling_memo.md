# 离线采样纪要（2026-11-23 当日封口）

## 事故

值班员把探头标离线后，在批批次仍接受该探头新采样写入，现场无读数温谱却继续叠点（幽灵曲线）。

## 根因

1. 批次挂接写口未刷新探头心跳态：`validate_probe_online` 空实现，离线不拦截写批次。
2. 探头离线审计谎称挂接已刷新（`batch_hooks_refreshed: true`）。
3. 采样写口无探头互斥锁；争用存痕随业务回滚一并丢失。

## 决议：单轨甲，第三路不留

**甲路径（选定）**：探头心跳离线 → 新采样正式行零增并拒写（409）。
写口每次实时读取 `probes.online_status`，非「在线」一律硬拒。

乙路径（缓存影子待传采样、心跳恢复后整笔晋升、否则作废）**不采用**：
本仓不建影子缓存表、不设晋升通道。两边不得混用——混用会出幽灵曲线。

## 偏离处置

任何向离线探头灌点的尝试：记 `audit_trail.action='离线采样偏航'` 并拒写。
偏航存证与锁释放同笔提交，不随业务回滚丢失。

## 并发口径

采样写口先占 `probe:{probe_id}` 互斥锁（全局锁序：探头锁 → 仓间锁），
再校验心跳。双人同时向同一离线探头所属批次灌采样：后到者 409 只存痕
（`contention_log` 独立提交），零业务写。

## 展示口径

校准页、对账页、仓间页、批次页、探头页五页同源：均以服务端为唯一事实源，
无本地合成点。被拒采样任何页面不得画出。

## 复现链与验收

- 假事故夹具与三测：`tests/test_offline_sample_gate.py`
  - 测甲 `test_offline_pour_rejected_zero_new_rows`：离线仍增采样行 → 红；修后零增拒写 → 绿。
  - 测乙 `test_unpromoted_points_never_drawn`：待传未晋升曲线已画 → 红；修后五页无幽灵点 → 绿。
  - 争用 `test_two_sessions_contend_same_offline_probe`：两会话同批抢灌点 → 红；修后只存痕 → 绿。
- 收工：三绿 + 全仓测试绿 + 五页无不实点。
